# EcoTrack: Carbon Footprint Engine
DSAA Course Mini-Project | UN SDG 13: Climate Action
## Overview
A carbon footprint accounting engine implementing custom low-level data structures from scratch:
- **Custom Hash Map (Separate Chaining):** Constant-time factor retrieval ($O(1)$)
- **Singly Linked List:** Pointer-based session audit logging with head insertion ($O(1)$)
